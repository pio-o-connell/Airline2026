# Airline2026 aircraft seat-map graphics

This package contains two reusable, transparent-background SVG aircraft outlines:

- `AC180.svg` — 180-seat aircraft outline.
- `AC220.svg` — 220-seat aircraft outline.

The SVGs contain structural artwork only: nose/cockpit, fuselage, wings, engines,
and tail. Interactive seat controls should be rendered separately as HTML and
positioned in a responsive layer over the cabin area.

Suggested destination in Airline2026:
`assets/Images/seatmaps/`

These are initial vector assets for integration and visual review. They do not
contain seat buttons, seat availability, booking logic, or database data.
